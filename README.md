#RedStore-E-Commerce-Website
#RedStore is a responsive e-commerce platform built with HTML5, CSS3, JavaScript (frontend) and Python Flask (backend).
#It integrates MySQL with SQLAlchemy ORM for database management.
#The project includes user authentication, registration, login system, dashboard, shopping cart, and Mini AI-based product recommendations.
                  🚀 #Features

🔐 #User Authentication – Registration & Login (MySQL + SQLAlchemy)

👤 #User Dashboard – Personalized shopping space

📦 #Product Catalog – Add, browse, and explore products

🛒 #Shopping Cart – Add, update, remove, checkout functionality

🤖 #Mini AI Recommendation – Static Mini AI-based product suggestions

📱 #Responsive Design – Works on desktop, tablet, and mobile

🗄️ #Database Integration – MySQL with SQLAlchemy ORM
